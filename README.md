## 项目

**[GeometryOS](https://github.com/GeometryOS)** — 维护者之一。基于 Android 深度定制的虚拟机系统（包含一些基于容器的神秘redroid虚拟机运行时）

**[QZXUI](https://qzxui.geometryos.cn/)** — 一套面向 Android 的 UI 组件库，围绕「页面 + 滚动 + 列表 + 材质」构建，用于打造美观、丝滑、现代的 Android 应用（即将开源）

**MCN** — Velocity 代理端群服互通插件，支持 Web 面板管理与开放 API 拓展功能。暂未开源发布

**[VerseBox A9 Runtime](https://github.com/GeometryOS/VerseBox-guest-runtime-a9)** — GeometryOS 的 API 28 运行时，让旧版 Android 固件在现代手机上运行。 `C/C++`

**[node_status_server_open_source](https://github.com/xfy2412/node_status_server_open_source)** — 轻量级服务器状态实时监控。 `JavaScript`
