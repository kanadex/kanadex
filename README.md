- **[GeometryOS](https://github.com/GeometryOS)**

  维护者之一。基于 Android 深度定制的虚拟机系统（包含一些基于容器的神秘 redroid 虚拟机运行时）。

- **[QZXUI](https://qzxui.geometryos.cn/)**
  <br/>
  一套面向 Android 的 UI 组件库，围绕「页面 + 滚动 + 列表 + 材质」构建，用于打造美观、丝滑、现代的 Android 应用（即将开源）。
